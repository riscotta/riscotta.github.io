# Fonte Quarto da versão técnica pública

Esta pasta preserva a estrutura Quarto pública aprovada na E02 e atualizada operacionalmente na E06.

Ela não contém o manuscrito canônico nem o EPUB RC07.

A publicação de capítulos, códigos, dados, exercícios e figuras depende de autorização e das verificações de direitos/proveniência aplicáveis. A página HTML pública em `/bayes-r-stan/` é a camada atualmente servida pelo GitHub Pages.
