# ricardoscotta.github.io

Site autoral de Ricardo Scotta.

O repositório publica o portfólio editorial em `ricardoscotta.com.br`, reunindo livros, projetos em desenvolvimento, materiais técnicos, erratas, atualizações e páginas institucionais.

## Estrutura principal

- `/` — apresentação autoral e visão geral do catálogo;
- `/livros/` — catálogo de livros publicados e em desenvolvimento;
- `/livro/` — página preservada do livro *Estatística Bayesiana com R e Stan* para compatibilidade com links já divulgados;
- `/bayes-r-stan/` — versão técnica pública do livro;
- `/sobre/` — apresentação do autor;
- `/errata/` — registro de correções por obra;
- `/privacidade/` — política de privacidade e tratamento do cadastro editorial.

O GitHub Pages publica a partir da branch `main`. Alterações estruturais são desenvolvidas em branch própria e integradas por pull request.
